# Demo video script (≤ 3 minutes)

> Requirement: *up to 3 minutes, showing your core flow working.* Show it working on testnet, and make the Concordium part visible (wallet popups, CCDExplorer).

| Time | Scene | What to show / say |
|---|---|---|
| 0:00–0:20 | Problem | The trust failure, in one sentence |
| 0:20–0:40 | Product | What the agent does and who uses it |
| 0:40–2:20 | Core flow | Live run: happy path plus one **rejected** case (unverified agent / over budget / no consent) |
| 2:20–2:40 | Proof | CCDExplorer: agent registration, anchors, payments |
| 2:40–3:00 | Path to production | Next steps to mainnet |

## Recording checklist
- [ ] Wallet on **testnet**, with enough test CCD
- [ ] No private keys or seed phrases visible on screen
- [ ] CCDExplorer tabs pre-opened
- [ ] Video uploaded as **public / unlisted** and the link works while logged out
